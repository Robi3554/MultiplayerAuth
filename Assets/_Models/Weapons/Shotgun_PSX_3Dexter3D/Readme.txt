Optional Optimization:


To reduce object impact further: open the Shotgun_PSX.blend file and shift select the individual pieces of the shotgun which will NOT be moving (aka: static meshes) and combine with CTRL+J, finally, export via File -> Export -> .fbx/.obj -> Save

This file will be the same as the ones provided in the downloaded pack. Except, the game engine you import your file to will now render less total meshes each time the shotgun is rendered. 

"Shotgun_OnePiece/Shotgun_Prop" Is an example of this wherein the entire mesh is combined into one object; This specific object is not customizable or animatable because of this.
